# Roteiros de exemplo

Cole qualquer um destes no campo "Cole o seu roteiro" para testar. Não são limitados a "E se...?": há POV de zumbi, animais, crime,
documentário e ciência.

Marcadores aceitos no roteiro (não são narrados):
- `---` ou `===` em uma linha sozinha: começa um novo episódio.
- `Parte 2`, `Episódio 3: Título`, `Capítulo 1 - Título`: também começam um novo episódio (o título vira o título do episódio).
- `[direção entre colchetes numa linha só]`: nota visual para a próxima cena, não é narrada.
O resto é narração e é preservado palavra por palavra.
