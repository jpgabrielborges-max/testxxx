# Efeitos sonoros (opcional)

O app sintetiza os efeitos (whoosh, impact, boom, rumble, riser, heartbeat, wind, drone). Se quiser sons reais, coloque aqui
arquivos **que voce tenha direito de usar** (ex.: CC0), com o nome do efeito no comeco: `whoosh_01.wav`, `boom.mp3`,
`heartbeat_slow.ogg`. Se existir arquivo com esse nome, ele substitui o som sintetico.
